3. Placeholders you still need to fill in

All of these live in .env. Nothing is hard-coded in the source.
SettingWhere to get it
SYNCRO_SUBDOMAINThe first part of your Syncro web address — yourfirm in yourfirm.syncromsp.com.
SYNCRO_API_KEYSyncro → Admin → API Tokens → New Token. Needs Invoices (view) and Payments (view + create).
DOJO_API_KEYdeveloper.dojo.tech → your app's keys. sk_sandbox_... to test, sk_prod_... when live.
DOJO_SOFTWARE_HOUSE_IDIssued by Dojo when they onboard you as an EPOS integrator.
DOJO_RESELLER_IDIssued by Dojo alongside the software-house id.
DOJO_TERMINAL_IDOptional. Leave blank to auto-pick an available machine; the check above lists the ids it can see.
BRIDGE_TOKENInvent a long random string. node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
